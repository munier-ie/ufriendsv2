Introduction

Ufriends Developer API

v1.0.0  ·  Live

The Ufriends API lets your application purchase airtime, data bundles, cable TV subscriptions, electricity units, exam pins, and generate NIN/BVN identity slips — all from a single REST interface.

Base URL https://ufriends.com.ng/api/v1
🔑
Vendor Access Only. The external API is available exclusively to Vendor accounts. Upgrade your account →

Quick-start checklist

1. Register / log inCreate your Ufriends account and upgrade to Vendor.
2. Get your API KeyGET /api/auth/api-key (JWT-authenticated)
3. Fund your walletDeposit funds — purchases are deducted from your wallet.
4. Make your first callSee the Services section below.
Auth

Authentication

All /api/v1/* requests must include your API key as a Bearer token in the Authorization header.

HTTP Header
Authorization: Bearer YOUR_API_KEY

Getting Your API Key

Log in with JWT first, then call:

cURL
# Step 1 — Login (get JWT)
curl -X POST https://ufriends.com.ng/api/auth/access \
  -H "Content-Type: application/json" \
  -d '{"email":"you@example.com","password":"yourpassword"}'

# Step 2 — Get API Key (use JWT from step 1)
curl https://ufriends.com.ng/api/auth/api-key \
  -H "Authorization: Bearer YOUR_JWT_TOKEN"
⚠️
Never expose your API key client-side (browsers, mobile apps). Store it in environment variables on your server.

Rotating Your API Key

Immediately invalidates the old key and issues a new one — no PIN required.

cURL
curl -X POST https://ufriends.com.ng/api/auth/api-key/regenerate \
  -H "Authorization: Bearer YOUR_JWT_TOKEN"

All error responses follow a consistent shape:

{
  "status":    1,
  "message":   "Insufficient wallet balance. Required: ₦500.00, Available: ₦120.00",
  "errorCode": 4400   // optional — see table below
}

200 OK—Request succeeded. success: true
400—Bad request — validation error or business rule failure

Reference

Rate Limits

Vendor accounts may make up to 300 requests per minute. When exceeded, the API returns a 429 response with a retryAfter field (seconds until reset).

429 Response
{
  "status":     1,
  "message":    "Rate limit exceeded",
  "errorCode":  4029,
  "retryAfter": 12   // wait 12 seconds
}

Webhooks

Register an HTTPS URL to receive real-time push notifications whenever a transaction occurs. Payloads are signed with HMAC-SHA256 so you can verify they came from Ufriends.

ℹ️
Your webhook URL must be publicly accessible via HTTPS. Private/local URLs are blocked for security.
POST /api/v1/webhook/configure Set webhook URL
cURL
curl -X POST https://ufriends.com.ng/api/v1/webhook/configure \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{ "webhookUrl": "https://yourdomain.com/ufriends-webhook" }'
JSON · 200
{
  "success":   true,
  "message":   "Webhook configured successfully",
  "secretKey": "a1b2c3d4e5f6..."   // Save this! Used to verify signatures.
}
⚠️
Save secretKey immediately — it will not be shown again. Use it to verify all incoming webhook payloads.
POST /api/v1/webhook/test Send a test event
cURL
curl -X POST https://ufriends.com.ng/api/v1/webhook/test \
  -H "Authorization: Bearer YOUR_API_KEY"
GET /api/v1/webhook/config  ·  /logs  ·  POST /regenerate-secret
MethodPathDescription
GET/api/v1/webhook/configView current webhook URL & secret
GET/api/v1/webhook/logsView last N delivery attempts (default 20)
POST/api/v1/webhook/regenerate-secretRotate signing secret (old secret invalidated immediately)

Verifying Signatures

Every webhook request includes an X-Ufriends-Signature header. Always verify it before processing the payload.

Node.js (Express)
const crypto = require('crypto');

app.post('/ufriends-webhook', express.json(), (req, res) => {
  const signature = req.headers['x-ufriends-signature'];
  const expected  = crypto
    .createHmac('sha256', process.env.UFRIENDS_WEBHOOK_SECRET)
    .update(JSON.stringify(req.body))
    .digest('hex');

  if (signature !== expected) {
    return res.status(401).send('Invalid signature');
  }

  const { event, data } = req.body;

  switch (event) {
    case 'transaction.success':
      // fulfil order, notify customer ...
      break;
    case 'transaction.failed':
      // alert customer, log issue ...
      break;
  }

  res.sendStatus(200); // Always respond 200 quickly
});
PHP
<?php
$secret    = getenv('UFRIENDS_WEBHOOK_SECRET');
$body      = file_get_contents('php://input');
$signature = $_SERVER['HTTP_X_UFRIENDS_SIGNATURE'] ?? '';
$expected  = hash_hmac('sha256', $body, $secret);

if (!hash_equals($expected, $signature)) {
  http_response_code(401);
  exit('Invalid signature');
}

$payload = json_decode($body, true);
$event   = $payload['event'];

// handle $event ...
http_response_code(200);

Code Samples

Full integration examples in Node.js and PHP.

Node.js — Full Integration
const API_KEY  = process.env.UFRIENDS_API_KEY;
const BASE_URL = 'https://ufriends.com.ng/api/v1';

async function ufriends(method, path, body) {
  const res = await fetch(`${BASE_URL}${path}`, {
    method,
    headers: {
      'Authorization':  `Bearer ${API_KEY}`,
      'Content-Type':   'application/json'
    },
    body: body ? JSON.stringify(body) : undefined
  });
  return res.json();
}

// 1. Check balance
const bal = await ufriends('GET', '/wallet/balance');
console.log('Balance:', bal.wallet);

// 2. List MTN data plans
const plans = await ufriends('GET', '/services/data');
const mtn1gb = plans.services.find(s => s.name.includes('MTN 1GB'));

// 3. Buy data
const result = await ufriends('POST', '/services/purchase', {
  serviceId: mtn1gb.id,
  recipient: '08012345678',
  amount:    mtn1gb.price
});
console.log(result.success ? '✅ Delivered!' : '❌ Failed: ' + result.message);

// 4. Generate NIN slip
const nin = await ufriends('POST', '/identity/nin', {
  nin:      '12345678901',
  slipType: 'regular'
});
console.log('NIN PDF:', nin.report?.pdfUrl);
PHP — Full Integration
<?php
define('UFRIENDS_KEY', getenv('UFRIENDS_API_KEY'));
define('UFRIENDS_URL', 'https://ufriends.com.ng/api/v1');

function ufriends($method, $path, $body = null) {
  $ch = curl_init(UFRIENDS_URL . $path);
  curl_setopt_array($ch, [
    CURLOPT_RETURNTRANSFER => true,
    CURLOPT_CUSTOMREQUEST  => $method,
    CURLOPT_HTTPHEADER     => [
      'Authorization: Bearer ' . UFRIENDS_KEY,
      'Content-Type: application/json'
    ],
    CURLOPT_POSTFIELDS     => $body ? json_encode($body) : null
  ]);
  $response = curl_exec($ch);
  curl_close($ch);
  return json_decode($response, true);
}

// Check balance
$bal = ufriends('GET', '/wallet/balance');
echo 'Balance: ₦' . $bal['wallet'];

// Buy airtime
$result = ufriends('POST', '/services/purchase', [
  'serviceId' => 10,
  'recipient' => '08012345678',
  'amount'    => 500
]);
echo $result['success'] ? 'Delivered!' : $result['message'];

// BVN verification
$bvn = ufriends('POST', '/identity/bvn', ['bvn' => '12345678901']);
echo $bvn['report']['pdfUrl'];
